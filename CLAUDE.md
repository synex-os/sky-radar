# Небесный радар

Личное некоммерческое веб-приложение автора: видеть всё, что происходит на небе над головой.
Самолёты, спутники и МКС, Луна, планеты, звёзды. Режим «купол» (карта всего неба) и AR-режим
(метки поверх камеры по компасу). Это ещё и учебный проект: автор хочет понимать, как всё устроено.

## Как работать с автором
- Объяснять образно и коротко, без вывода формул: «быстрый мозг», детали утомляют, хочется двигаться.
  Формулы живут в коде, в разговоре — картинка (пушка Ньютона, глобус изнутри, зеркальце на солнце).
- Собирать по шагам, чтобы каждый слой можно было проверить на балконе.
- Интерфейс на русском. Бюджета на железо нет: всё на телефоне и бесплатных данных.

## Что уже есть (шаг 1, готов)
- `src/astro.js` — «мозг»: звёздное время, перевод небесных координат в азимут/высоту,
  Солнце, Луна (с параллаксом и фазой), Меркурий–Сатурн (алгоритмы Шлайтера, точность ~угловые минуты),
  рефракция, прецессия звёзд из J2000, поиск восходов/заходов. Работает и в Node (module.exports).
- `src/stars.js` — ~80 ярких звёзд (RA в часах, Dec в градусах, величина, расстояние в св. годах, созвездие)
  и линии фигур созвездий.
- `src/app.js` — купол на canvas (зенит в центре, восток слева), карточки объектов с объяснениями,
  перемотка времени ±, «что увидеть этой ночью», выбор места.
- `src/template.html` — разметка и стили. `python3 build.py` собирает один файл `index.html`
  (astro + stars + satellite.js + sats + planes + app + ar).
- Проверка 19.10.2026, место по умолчанию из списка в app.js: закат 18:03, восход 06:47 (UTC+3), Луна ~60% растущая,
  Сатурн у противостояния (элонгация ~164°, выше всего ~23:30), Венера у нижнего соединения (элонгация ~10°).

## Шаг 2 — спутники и МКС (готов)
- `vendor/satellite.min.js` — satellite.js 5.0.0 (MIT, SGP4), вшивается в index.html при сборке, без CDN.
- `src/sats.js` — загрузка TLE (сначала `data/*.tle` на нашем сайте, потом CelesTrak напрямую, потом
  кэш localStorage; свежим кэш считается 3 ч), разбор, положение (азимут/высота/дальность), тень Земли
  (цилиндр), яркость (стандартная величина + фаза диффузного шара), след на ±минуты, поиск видимых пролётов
  (грубо раз в минуту по одной высоте, подробно шагом 10 с только над горизонтом; ~40 мс на спутник-сутки).
  Своё имя/яркость/описание — в `SAT_INFO` (МКС 25544, Тяньгун 48274, Хаббл 20580).
- В `app.js`: слой спутников на куполе (мятные — на солнце и видны глазом, серые — в тени/днём; у трёх
  главных — путь −3…+6 мин, пунктир — пройденное), карточка спутника, блок «Пролёты» на сутки (клик по
  пролёту перематывает время к его середине), переключатели «Яркие спутники» / «Starlink» (Starlink грузится
  лениво и скрыт в режиме «Ускорить»).
- `.github/workflows/pages.yml` — сборка и выкладка на GitHub Pages при пуше в main и раз в 6 ч;
  кладёт свежие `data/{visual,stations,starlink}.tle`. В настройках Pages источник — **GitHub Actions**.
  `data/` в git не храним.
- Источники орбит (выяснено разведкой 23.10.2026):
  - CelesTrak `gp.php` с серверов GitHub соединяется через раз (подключение до ~40 с) → curl `-4`, длинные
    таймауты, `--retry 4`. `visual` (~155) и `stations` так приходят стабильно.
  - CelesTrak **Starlink** серверам GitHub отвечает 403 (и `gp.php`, и `sup-gp.php`) — не обходить.
    Берём из tle.ivanstanojevic.me (`tools/fetch_starlink.py`, ~124 страницы по 100, ~12 мин) не чаще раза
    в сутки; между сборками — прошлая копия с сайта (`data/starlink.updated` хранит время сборки).
  - С телефона CelesTrak тоже не ответил (у автора «Спутников: 3»), поэтому браузер полагается на `data/`.
  - tle.ivanstanojevic.me: CORS открыт, отдаёт TLE по номеру (`/api/tle/25544`) — запасной для трёх главных.
  - SatNOGS и AMSAT — радиолюбительские спутники, нам не подходят.
  - Отчёт задания читается через аннотации (`::notice::`); логи и ручной запуск workflow сессии недоступны.
- Проверено: положения МКС совпадают со skyfield до 0,08° (это рефракция) и 0,03 км; позиция ECI — с python sgp4.
  В облачной сессии Claude CelesTrak и *.github.io закрыты сетью — живые данные проверять на телефоне.
- Риск: каталожные номера NORAD подбираются к 99999, CelesTrak может перестать отдавать TLE для новых
  объектов (останется OMM/JSON). Тогда — перейти на `FORMAT=json` и satellite.js 6 (`json2satrec`).

## Шаг 3 — самолёты (готов)
- Разведка с GitHub 23.10.2026: adsb.fi и adsb.lol отдают данные, но **без CORS**; adsb.lol ещё и лимит
  500 запросов/сутки на IP; airplanes.live отвечает 403 серверам; OpenSky CORS только для своего сайта.
  → посредник обязателен.
- `worker/planes.js` — Cloudflare Worker: `?lat&lon&dist` (морские мили, ≤100) → по очереди adsb.fi, airplanes.live,
  adsb.one, adsb.lol, OpenSky (переводится в общий вид); отказавший с 403/429 источник — пауза 2 мин;
  ужимает поля, кэш 6 с по месту, округлённому до 0,1°; CORS только для `ALLOWED_ORIGINS`; `?probe=1` — разведка.
- Разведка `?probe=1` с Cloudflare 23.10.2026: adsb.fi, airplanes.live, adsb.one → 403 за 2 мс (воркеры
  отсекают сознательно); OpenSky → 522 (таймаут); **работает только adsb.lol** (днём бывал 429 — общий
  лимит IP Cloudflare). Блокировки не обходить (не подделывать UA и т.п.). Если adsb.lol станет часто
  отказывать — перенести посредника на площадку с другими адресами (Deno Deploy, Vercel).
- Pages переключён на «GitHub Actions» (23.10.2026): выкладывает только `pages.yml`.
  Ставится вручную через дашборд Cloudflare (`worker/README.md`), стоит на https://sky-radar-planes.isratars.workers.dev
  (при каждой выкладке задание проверяет его и пишет итог в аннотацию). Адрес — константа `PLANES_PROXY`
  в `src/planes.js` или поле на странице (localStorage `skyradar.planesProxy`).
- `src/planes.js` — WGS84 → ECEF → ENU (азимут/высота/дальность), упреждение по `gs`/`track`/`geom_rate`
  (большой круг), высота `alt_geom` (иначе `alt_baro`), «на земле» скрыт, старше 60 с — скрыт.
  `dubious` = нет MLAT и (`nic`=0 или `nac_p`≤4) — признак GPS-помех, рисуется пунктирным контуром.
  Словарь авиакомпаний по префиксу позывного — `AIRLINES`.
- `app.js`: слой самолётов (острие — куда будет через 20 с), карточка, блок «Самолёты рядом» (6 ближайших),
  опрос раз в 5 с, только когда вкладка видна и время «сейчас»; в перемотке самолёты скрыты.
- Проверено: геометрия совпала со skyfield до 0,001° и 1 м; упреждение — 9,607 км за минуту при ожидаемых 9,609;
  посредник протестирован в Node с подменённым fetch (кэш, запасной источник, отказ при мусоре).
- Атрибуция: ссылка на фактический источник в строке статуса (условие adsb.fi; ODbL у adsb.lol).

## Шаг 4 — камера и компас (готов, ждёт проверки на телефоне)
- `src/ar.js` (подключается после app.js; данные берёт из `window.SkyApp` = state, store, select, fmt, goNow).
  Кнопка «Навести телефон на небо» → полноэкранный `#ar`: задняя камера (`getUserMedia`, environment),
  поверх canvas: горизонт, стороны света (С — красная), созвездия, звёзды, планеты, Солнце, Луна,
  спутники (`satView`), самолёты (`planes.view`), перекрестье; выбранный объект — кольцо или стрелка у края.
- Ориентация: `deviceorientationabsolute` (Android) / `deviceorientation` + `webkitCompassHeading` (iOS:
  alpha = 360 − heading; разрешение `DeviceOrientationEvent.requestPermission` первым делом в обработчике нажатия).
  Углы → матрица W3C (Z-X'-Y''), × Rz(screen.orientation.angle); сглаживание смешиванием 0,2 + Грам — Шмидт.
  Проекция: пинхол вдоль −z телефона, фокус по длинной стороне экрана и `fov` (ползунок, по умолчанию 66°).
- Поправка компаса `yawFix` (localStorage `skyradar.arYaw`): «Подогнать» берёт ближайшее к перекрестью светило
  (Солнце, Луна, планеты, звёзды ярче 1,5) в пределах 30° и сдвигает азимут; «Сброс» обнуляет.
- Без датчиков (компьютер) — ручной режим: водишь пальцем/мышью. Wake Lock держит экран включённым.
- Проверено в Chromium с поддельной камерой и синтетическими событиями: наведение на Луну → Луна ровно в центре
  (0 px), ошибка компаса 12° → «Подогнать» возвращает в центр; стрелка у края; выход останавливает камеру.
  **Не проверено на живом телефоне** (особенно iPhone: смысл `webkitCompassHeading` при вертикальном телефоне).

## Хостинг
Камера, компас, геолокация и внешние данные требуют обычного сайта по HTTPS (в окне артефакта Claude они
заблокированы). План: GitHub Pages (бесплатно), открыть на телефоне, «Добавить на главный экран».

## Важное
- В Израиле бывает GPS-спуфинг: самолёты «прыгают» на картах — хороший пункт глоссария.
- Перехваты и места падений не снимать и не публиковать (военная цензура).
