# Посредник для самолётов (Cloudflare Worker)

Источники ADS-B (adsb.fi, adsb.lol) не разрешают браузеру брать данные с чужого сайта.
Посредник `planes.js` забирает их сам и отдаёт сайту с разрешением, ужимает ответ и держит его в кэше 4 секунды.
Бесплатный тариф Cloudflare — 100 000 запросов в сутки; телефону нужно ~720 в час, пока страница открыта.

## Как поставить (5 минут, один раз)
1. Зарегистрируйся на https://dash.cloudflare.com/sign-up (карта не нужна).
2. Слева **Compute (Workers)** → **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World»).
3. Имя: `sky-radar-planes` → **Deploy**.
4. **Edit code** → удали всё в `worker.js` → вставь содержимое `worker/planes.js` → **Deploy**.
5. Скопируй адрес вида `https://sky-radar-planes.<твоё-имя>.workers.dev`.
6. Открой сайт → блок «Самолёты рядом» → вставь адрес → **Сохранить**.

Проверка: открой в браузере `https://sky-radar-planes.<твоё-имя>.workers.dev/?lat=32.33&lon=34.86&dist=60` —
должен прийти JSON со списком самолётов.

Если сайт переедет на другой адрес — добавь его в `ALLOWED_ORIGINS` в начале `planes.js`.
